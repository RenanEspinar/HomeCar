# HomeCar Attribution Notice

HomeCar is an independent open-source project developed by Renan Espinar.

HomeCar is derived from Fermata Media Player by Andrey Pavlenko.

Original Fermata repository:
https://github.com/AndreyPavlenko/Fermata

HomeCar modifications include, among others:

- Home Assistant focused interface
- Direct WebView dashboard startup
- Configurable server URL
- Persistent Home Assistant server configuration
- HomeCar branding
- Full-screen dashboard interface
- Simplified Android Auto launcher
- Disabled unused mirroring launcher entries
- Modified Android Auto startup behavior
- Universal APK workflow
